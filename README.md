# android_vendor_xiaomi_dada-miuicamera

MiuiCamera / MiuiExtraPhoto proprietary blobs for Xiaomi 15 from HyperOS 4 **OS4.0.0.22.XOCCNXM**.

Requires **git-lfs** (`*.apk`, `*.so`). `MiuiCamera.apk` is ~190MB.

```bash
git lfs install
git clone -b lineage-23.2 https://github.com/devine-machinery/android_vendor_xiaomi_dada-miuicamera.git
```
